資料工程與處理

負責醫療文本去識別化處理、清洗與標記，確保資料符合模型訓練規範並保護患者隱私。

模型訓練與評估

微調（Fine-tuning）大型語言模型，並建立多維度評估指標，確保補全結果的醫學專業度與精確度。

後端與資料庫開發

基於 FastAPI 建構高效非同步 API，並設計 MySQL 資料庫架構以維護護理紀錄之完整性。

UI 介面設計與開發

獨立開發前端 React 介面，優化護理人員操作流，完成從概念原型到正式部署的完整開發週期。

專案背景

在臨床環境中，護理師需處理大量病患資訊，頻繁的文書作業（護理紀錄）常佔據約 30% 的工時。本專案目標在於開發一套能理解關鍵字速記的 AI 系統，透過 LLM 技術將碎片資訊自動轉化為標準醫學格式，大幅降低醫療行政負擔。
