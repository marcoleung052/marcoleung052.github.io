HealthTech 2024 - 2025 Project

AI-Assisted Nursing Record System
護理紀錄語音自動補全系統

Large Language Model (LLM) FastAPI React MySQL Docker

極速補全

將護理師隨手速記的片段字詞，一鍵補全為符合醫療規範的正式護理紀錄。

多模態輸入

支援語音轉文字 (STT) 與文字速記，解決護理人員在病房中書寫不便的痛點。

資料隱私

去識別化處理 (De-identification) 機制，確保患者隱私符合醫療法規規範。

專案背景與痛點

在現有的醫療環境中，護理人員每天需花費約 **30% 的時間** 撰寫病程紀錄。高壓的工作環境下，護理師往往僅能使用零碎字詞進行速記，事後再花費大量時間整理，這不僅增加了行政負擔，也容易造成醫療資訊遺漏。

本專案透過微調（Fine-tuning）LLM 模型，學習台灣醫療體系常用的術語與紀錄格式，打造一套能理解「護理速記」並自動生成「標準紀錄」的輔助系統。

技術架構與流程

前端開發

使用 **React** 建立響應式介面，整合語音錄製 API，提供護理師最直觀的操作體驗。

後端與 AI

基於 **FastAPI** 構建非同步服務，透過微調過的 LLM 模型進行文本推論與專業格式化。
