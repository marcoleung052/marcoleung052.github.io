ResNet50 特徵提取

使用 ResNet50 作為基礎架構，透過遷移學習 (Transfer Learning) 進行微調 。整合 torchvision 圖像增強技術，精準提取服飾影像的高維 Embedding，作為相似度計算的基礎 。

FAISS 高效向量檢索

導入 Meta 開發的 FAISS 向量數據庫，實現百萬級資料量下的毫秒級檢索 。透過向量量化與 GPU 加速，大幅優化以圖搜圖的反應速度與擴展性 。

系統開發流程

數據處理與增強

針對 DeepFashion 數據集進行隨機裁切、旋轉與色彩調整，增加樣本多樣性並防止模型過擬合。

模型訓練與評估

定義 Baseline 模型並進行特徵提取與儲存，透過 Top-K 檢索結果進行系統精準度驗證。

Gradio UI 展示

開發雙模型比較介面，支持圖片上傳與 Top K 數量調整，視覺化呈現檢索結果差異。
