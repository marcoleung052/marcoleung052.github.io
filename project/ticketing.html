Software Engineering Project 2024.09 - 2024.12

威秀影城訂票系統
VieShow Ticketing System

Aiven MySQL Hugging Face Spaces Flask / Python RESTful API AI Agent (LLM) GitHub Pages
System Architecture: Cloud DB + HF Backend

展示內容：前後端分離架構與 AI 智慧助理互動介面

Aiven MySQL 資料庫設計

負責雲端資料庫的建立與維護，設計包含會員、電影、場次及訂單的關聯式結構。實現「會員資料修改」核心邏輯，確保資料在異步請求（AJAX）下的安全性與一致性。

AI 小助手後端整合

利用 Flask 架設後端 API 並部署於 Hugging Face，串接 LLM 實現智慧助理。支援查詢現正熱映、場次、餐點資訊及 FAQ 閒聊，大幅降低人工客服壓力。

系統實作流程

雲端環境搭建

配置 Aiven MySQL 雲端實例，設計資料表 schema，並設定 GitHub Actions 實現前端自動化部署。

後端 API 整合

使用 Python Flask 開發會員資料修改、點數儲存等 API，串接隊友製作的 HTML 前端介面，達成前後端分離。

AI 小助手上線

在 Hugging Face Spaces 上完成 AI 模型 API 串接，支援電影查詢、場次推薦與常見問題解答。
