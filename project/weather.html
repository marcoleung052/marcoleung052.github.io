澳洲降雨預測系統
Rain in Australia Prediction

Random Forest Data Mining OpenWeatherMap API Gradio UI SMOTE Scikit-learn Feature Engineering

隨機森林模型最佳化

採用隨機森林（Random Forest）分類器進行澳洲 49 個氣象站數據訓練，並透過 Grid Search 與 SMOTE 過採樣技術解決原始資料類別不均問題，提升對「降雨」類別的預測精準度。

即時氣象 API 整合

串接 OpenWeatherMap API 獲取全球即時氣象資訊，將實時溫度、濕度及風速數據自動映射至模型特徵，實現「輸入城市，立即預測」的無縫體驗。

預測與實作流程

數據清洗與工程

處理 10 年份的澳洲氣象日誌，包含缺失值插補、異常值剔除，並提取年份與月份作為季節性特徵。

特徵重要性分析

分析影響降雨的關鍵因素，如濕度（Humidity3pm）、氣壓及風向，優化模型特徵組合以提升預測效率。

Gradio 介面開發

建構直觀的 UI 介面，支援地圖選點或城市搜尋，動態呈現預測機率與氣象趨勢視覺化。
